# TPMMongoDB

MongoDB 連線與文件查詢工具。需求：VS Code 1.95+。

最新版：[0.1.1](https://github.com/troyliu/TPM-Releases/releases/tag/TPMMongoDB-v0.1.1) · [下載 tpmmongodb-0.1.1.vsix](https://github.com/troyliu/TPM-Releases/releases/download/TPMMongoDB-v0.1.1/tpmmongodb-0.1.1.vsix)

在 VS Code 命令面板執行 `Extensions: Install from VSIX...`，選擇下載的檔案。
