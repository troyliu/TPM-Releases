# TPMRedis

Redis 連線與資料瀏覽工具。需求：VS Code 1.95+。

最新版：[1.0.1](https://github.com/troyliu/TPM-Releases/releases/tag/TPMRedis-v1.0.1) · [下載 tpmredis-1.0.1.vsix](https://github.com/troyliu/TPM-Releases/releases/download/TPMRedis-v1.0.1/tpmredis-1.0.1.vsix)

在 VS Code 命令面板執行 `Extensions: Install from VSIX...`，選擇下載的檔案。
